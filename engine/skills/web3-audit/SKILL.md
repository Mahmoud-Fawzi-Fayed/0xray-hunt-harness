# Web3 Smart Contract Audit

Complete vulnerability catalog, stack routing, and PoC examples: [references/full-guide.md](references/full-guide.md).

Start with value flows, trust boundaries, and invariants. Map every privileged and externally reachable path, test one assumption at a time, and prove the detected condition with a reproducible local/fork transaction. Static pattern matches and theoretical impact are not findings without a demonstrated state or asset effect.
